# 실습과제 #3 출발선 키트 (web-hw3a)

실습과제 #3 「살아 움직이는 영화 보드」를 **Step 0이 끝난 상태**에서 시작하게 해 주는 파일 4개입니다(교수 제공).<br>
이 파일들로 내 저장소 `web-hw3`를 시작하면 안내문(그리고 12주차 영상 수업 4차시)의 Step 1부터 그대로 따라 할 수 있습니다.

## 누구를 위한 것인가요

- 실습과제 #1(`web-hw1`)이나 #2(`web-hw2`)를 끝내지 못한 학생
- 11주차, 12주차 수업 실습(12주차 저장소)을 하지 못한 학생
- #1, #2와 12주차 저장소가 모두 있다면 이 키트 없이 안내문의 "세 저장소에서 가져올 것" 표대로 합니다.

## 들어 있는 것

| 파일 | 들어 있는 것 | Step 1부터 내가 할 일 |
|---|---|---|
| `index.html` | #1 모양의 헤더, 히어로, 푸터(TMDB 고지, KOBIS 출처)와 Step 0의 `<main>`(툴바, 보드, 빈 결과 문구, `<dialog>`). `</body>` 앞에 `data.js`, `app.js` | 사이트 이름, 히어로 문구, 푸터의 KOBIS 기준일을 내 것으로 |
| `style.css` | #1의 색 변수, 헤더, 히어로, 보드 격자(1열, 2열, 4열), 카드, 배지, 대체 표지, 푸터 + 맨 아래 11주차, 12주차 규칙(`.card.hot .badge`, `.toolbar`, `.like`, `.state-empty`) | 색과 글꼴을 내 디자인으로(선택), Step 4의 `dialog::backdrop`(선택) |
| `data.js` | 영화 객체 형식 예시 2건과 값 찾는 법(TMDB, KOBIS 주소창) | 10건(내 영화 5편, 박스오피스 5편)으로 채우기, Step 1에서 `overview` 더하기 |
| `app.js` | 함수 4개: `posterUrl`, `sortBy`, `search`, `renderCards`(11주차 수업 실습을 마친 모양). 실행하는 줄은 없음 | Step 1의 `renderCards` 네 군데 ⇒ Step 2 `getView` ⇒ Step 3 찜 ⇒ Step 4 상세 |

## 쓰는 법

1. 내 저장소 만들기:<br>
   GitHub에서 New repository ⇒ 이름 `web-hw3` ⇒ **Public** ⇒ **Add a README file 체크** ⇒ Create repository.<br>
   Settings ⇒ Pages ⇒ `main`, `/ (root)` ⇒ Save.
2. 파일 4개 가져오기:<br>
   이 저장소에서 `index.html`, `style.css`, `data.js`, `app.js`를 하나씩 클릭 ⇒ "Raw" 옆 복사 아이콘(Copy raw file) ⇒ 내 `web-hw3`에 같은 이름의 새 파일을 만들어 붙여 넣기.<br>
   또는 이 저장소의 Code ⇒ Download ZIP으로 받아 풀고 4개 파일만 내 저장소 폴더에 넣습니다.<br>
   이 `README.md`는 가져오지 않습니다(내 README는 안내문 맨 아래 양식으로 씁니다).
3. `data.js` 채우기:<br>
   형식 예시 2건을 내 값으로 바꾸고 같은 형식으로 8건을 더해 10건을 만듭니다(값 찾는 법은 `data.js` 맨 위 주석).<br>
   푸터의 KOBIS 기준일도 내 값으로 바꿉니다.
4. 커밋 `hw3 시작`:<br>
   사이트 주소 `https://아이디.github.io/web-hw3/`을 엽니다.<br>
   헤더, 툴바, 푸터가 보이고 카드가 아직 없으면 정상입니다(그리는 줄은 Step 1에서 넣습니다).
5. Step 1부터:<br>
   안내문의 Step 1(렌더링)부터 차례대로 합니다.

## 할 일 목록(Todo Tree, 선택)

키트의 코드에는 Step 1부터 남은 일을 적은 `TODO Step n` 주석이 12줄 있습니다(`index.html` 1, `data.js` 2, `app.js` 9).<br>
VS Code 확장 Todo Tree(제작자 Gruntfuggly)를 설치하면 왼쪽 막대의 나무 모양 아이콘에 이 줄들이 모여 보이고, 누르면 그 줄로 갑니다(설치는 PC실 안내서 7-4절).<br>
확장이 없으면 VS Code에서 `Ctrl+Shift+F`로 `TODO`를 검색해도 같은 목록이 나옵니다.<br>
한 가지를 끝내면 그 `TODO` 줄을 지웁니다. 남은 `TODO`가 남은 일이지만, 완성 여부는 안내문의 요구사항 1~9로 판단합니다.

## 규칙

- 손코딩 원칙: Step 1부터 더하는 코드는 직접 타이핑합니다(VS Code의 Emmet 자동완성은 써도 됨). 생성형 AI로 코드를 만들어 붙이는 것은 금지입니다.
- 생성형 AI 규칙: ❌ 코드 생성·수정 요청, 해답 요청, 문안 생성 / ⭕ 개념 질문, 오류 메시지 뜻 물어보기, 영어 문서 번역 / 📝 사용했다면 README에 질문과 답변 요약 기록(기록은 감점 아님, 미기록은 감점).
- 키 금지: #3 본 과제에는 API 키가 필요 없습니다. 키는 주소창에서 값을 찾을 때만 쓰고, `index.html`, `style.css`, `data.js`, `app.js`에는 적지 않습니다. 보너스를 하면 키는 `keys.js` 한 곳에만 둡니다(안내문 보너스 절).
- 출처: 푸터의 TMDB 고지(한국어와 영어 원문)와 KOBIS 출처, 기준일은 지우지 않습니다(출처 표기는 채점 항목).
